# ELECTIVA III PWA · Atlas 3D (Módulo AR)

Proyecto del Sub-bloque B de la Electiva III – Progressive Web Apps (PWA), Bloque 3: el Atlas 3D, un visor de
modelos de arquitectura en 3D con realidad aumentada, construido desde cero (sesiones 27 a 45).
Ingeniería de Sistemas y Computación · UPTC (Tunja).

El Sub-bloque A (fundamentos, sesiones 15 a 26) y el Gestor de Tareas están en su propio repositorio:
**[GESTOR-DE-TAREAS-PWA](https://github.com/AnthonyGonzalez1/GESTOR-DE-TAREAS-PWA)**. Los enlaces de este
repositorio que apuntan a esas sesiones (por ejemplo, «Espejo de la Sesión 19») abren allá.

Abre **`00 - Pagina del Bloque 3.html`** para navegar las presentaciones y guías sin conexión.

## Estructura

- `Sub-bloque B - Proyecto Modulo AR (Objetos 3D)/`: sesiones 27 a 45.
- Cada sesión incluye `presentacion.html`, `guia.html`, la guía en Word y, si aplica, el guion de clase y la carpeta `recursos/` (zip original + contenido extraído).
- Sesiones 39 a 45: la carpeta `entregables/` tiene las actividades resueltas (`ENTREGABLES.md`), el código de cada una (`codigo/*.diff`), las salidas de las pruebas y las capturas.
- `Proyectos/`: la versión más reciente de cada proyecto, actualizada sesión a sesión.
