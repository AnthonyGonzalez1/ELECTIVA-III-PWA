Antes de empezar

Atlas 3D de Arquitectura de Software

Un catálogo interactivo en 3D de ocho patrones y arquitecturas de software. Cada uno se ve como un modelo 3D construido con formas simples — y el propio proyecto está organizado usando varios de esos mismos patrones.

8 patronesCapas, MVC, Árbol Binario, Cliente-Servidor, Cliente-Caché-Servidor, Microservicios, Pub/Sub, Repositorio.
Se enseña a sí mismoEl contenido (los patrones) y el código (cómo está armado) son la misma idea, vista dos veces.
18 sesionesCada una espejo de un tema de fundamentación, aplicado a este mismo proyecto.

SECCIÓN 01

Por qué crear (y no clonar)

npm create vite@latest genera el andamiaje mínimo, archivo por archivo — para entender cada pieza.

vanilla-ts+ three
Scaffolding · 1.1

Cuatro comandos, un proyecto real

Terminal
npm create vite@latest pwa-ar-objetos3d -- --template vanilla-ts
cd pwa-ar-objetos3d
npm install
npm install three
Dato clave: three es la misma librería, y renderer.setAnimationLoop el mismo bucle de dibujo, que en las Sesiones 38-39 se reutiliza para realidad aumentada con WebXR.
SECCIÓN 02

Arquitectura de carpetas: capas + MVC

Cuatro capas con una única responsabilidad cada una — y el mismo patrón MVC visto desde otro ángulo.

dominiodatosvistacontrolador
Arquitectura · 2.1

src/, en cuatro capas

src/ ├── dominio/ // Modelo ├── datos/ // Los 8 patrones (seed) ├── vista/ // Vista — escena 3D └── controlador/ // Controlador
Arquitectura · 2.2

Las mismas 4 capas son MVC

Modelo

dominio/ + datos/

Vista

vista/

Controlador

controlador/

Mapa de destino: ninguna de estas capas existe todavía — hoy el proyecto solo tiene el andamiaje de Vite y el manifest. Cada capa llega, con su primer archivo real, a lo largo del Sub-bloque B.

Resumen de la lección

  • El proyecto se crea con npm create vite@latest — nunca clonado.

  • El manifest.json aplica exactamente lo aprendido en la Sesión 16.
