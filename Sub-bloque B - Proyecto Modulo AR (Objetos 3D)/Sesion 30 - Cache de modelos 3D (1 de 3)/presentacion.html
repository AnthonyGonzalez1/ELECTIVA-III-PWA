Todavía no hay modelos 3D — y ese es el punto

El Atlas 3D, al cierre de la Sesión 29, no tiene ningún archivo .glb ni .gltf. src/main.ts sigue mostrando el mensaje de arranque; el Service Worker solo cachea el shell ('/', '/index.html', '/manifest.json').

Por qué la sesión se llama así entonces: cuando los modelos lleguen, más adelante en el Sub-bloque B, vas a necesitar exactamente esta misma interfaz — put() asset por asset, y versionado para no acumular basura. Hoy la practicamos sobre lo que sí existe: los íconos y el manifest.
SECCIÓN 01

Aplicando la interfaz Cache

put() para los íconos, keys()+delete() para versionar — sobre el sw.js real del Atlas 3D.

cache.put()caches.keys()caches.delete()
Aplicando la interfaz Cache · 1.1

put(): los íconos, uno por uno

sw.js (fragmento)
const ICON_ASSETS = [
  '/iconos/icon-192.png', '/iconos/icon-512.png', '/iconos/icon-512-maskable.png',
];

async function guardarIconos(cache) {
  for (const url of ICON_ASSETS) {
    const respuesta = await fetch(url);
    await cache.put(url, respuesta);
  }
}
Es lo que addAll() hace por dentro, pero un asset a la vez — control total para cuando un modelo 3D falle su descarga.
Aplicando la interfaz Cache · 1.2

keys() + delete(): versionar el caché

sw.js (fragmento)
const CACHE_NAME = 'atlas3d-v2'; // antes: 'atlas3d-v1'

self.addEventListener('activate', event => {
  event.waitUntil(
    caches.keys().then(nombres =>
      Promise.all(nombres.filter(n => n !== CACHE_NAME).map(n => caches.delete(n)))
    ).then(() => self.clients.claim())
  );
});
Sube el nombre del caché y este bloque borra automáticamente cualquier versión que ya no coincida — sin esto, cada actualización futura acumula cachés huérfanos.
Aplicando la interfaz Cache · 1.3 — Caso real

El sw.js completo del Atlas 3D

public/sw.js
const CACHE_NAME = 'atlas3d-v2';
const CORE_ASSETS = ['/', '/index.html', '/manifest.json'];
const ICON_ASSETS = ['/iconos/icon-192.png', '/iconos/icon-512.png', '/iconos/icon-512-maskable.png'];

self.addEventListener('install', event => {
  event.waitUntil(caches.open(CACHE_NAME).then(async cache => {
    await cache.addAll(CORE_ASSETS);
    for (const url of ICON_ASSETS) { await cache.put(url, await fetch(url)); }
  }));
});
self.addEventListener('activate', event => {
  event.waitUntil(
    caches.keys().then(n => Promise.all(n.filter(x => x!==CACHE_NAME).map(x => caches.delete(x))))
      .then(() => self.clients.claim())
  );
});
self.addEventListener('fetch', event => {
  event.respondWith(caches.match(event.request).then(r => r || fetch(event.request)));
});
DevTools → Application → Cache Storage: un único caché, atlas3d-v2, con 6 entradas.
